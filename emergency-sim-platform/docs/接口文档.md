# 接口文档

## 1. 引擎 JS API（`src/engine/index.js`）

```js
import { runSimulation, paramsFromPresets, DEFAULT_PARAMS, assessResilience } from './engine/index.js'

const data = { facilities, population, roadNetwork /* 可选 */ }      // public/data 下的 JSON
const params = paramsFromPresets({ siteId: 'taihe', windPresetId: 'sw2' })   // 或自行构造（与 DEFAULT_PARAMS 深合并）
const result = await runSimulation(params, data, {
  onStage: ({ stage, status, ms, summary }) => {},   // status: running | done | skipped
  onLog:   ({ t, msg, level }) => {},                // level: info | warn | success | error
})
```

`assessResilience(result, supplyKey, evacKey)` 可按任意配送/疏散方案重新计算韧性雷达（界面切换方案时使用）。

## 2. REST API（`server/index.js`）

启动：`PORT=8787 DATA_DIR=./public/data STATIC_DIR=./dist node server/index.js`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/emergency/health` | `{ ok, version, roadNetwork }` |
| GET | `/api/emergency/config` | `{ defaults, sites, windPresets, stages, evacSchemes, supplySchemes }` |
| GET | `/api/emergency/reference` | 论文基准结果（`paper_reference.json`） |
| POST | `/api/emergency/simulate` | 完整结果（约 0.9 MB，含调度明细与几何） |
| POST | `/api/emergency/simulate?summary=1` | 摘要结果（不含调度明细、时间线与几何，约 15 KB） |
| POST | `/api/emergency/simulate?stream=1` | NDJSON 流，逐行：`{"type":"stage","payload":{...}}` / `{"type":"log","payload":{...}}` / `{"type":"result","result":{...}}` / `{"type":"error","message":"..."}` |

请求体：`{ "params": { ... } }`（也可直接传参数对象）。服务端先按 `siteId` / `windPresetId` 展开预设，再与显式参数深合并，例如：

```bash
curl -X POST 'http://localhost:8787/api/emergency/simulate?summary=1' \
  -H 'Content-Type: application/json' \
  -d '{"params":{"windPresetId":"n2","leakRateKgMin":10,"evacuation":{"fleet":{"ambulance":30}}}}'
```

### 2.1 主要参数（完整见 `src/engine/defaults.js` 的 `DEFAULT_PARAMS`）

| 字段 | 说明 | 默认 |
|---|---|---|
| `method` | `dual` 双链协同 / `evac` 仅疏散 / `supply` 仅物资 | `dual` |
| `algorithm` | `two_stage` 贪心+2-opt / `two_stage_direct` 直送优先 / `greedy` | `two_stage` |
| `siteId` / `incident` | 预设站点 id，或 `{lon, lat, name}`（WGS84） | `taihe` |
| `windPresetId` | `sw2` `sw3` `n2` `e2` `sw5` `sw1f` `sw7` | `sw2` |
| `gas` `leakRateKgMin` `leakDurationMin` `releaseHeightM` | 泄漏源 | 氯气 / 5 / 60 / 2 |
| `windSpeed` `windDir` `stability` | 风速 m/s、风向（来向，度）、稳定度 A–F | 3 / 225 / D |
| `plume.extentM` `plume.cellM` | 浓度网格半宽与分辨率 | 10000 / 50 |
| `zoneMode` `zoneBuffersM` | `buffered`/`contour`/`auto`；外扩距离 | buffered；500/1500/3000 |
| `population.mode` `population.k1Ratio` | `intersect`/`area`；重伤比例 | intersect；0.02 |
| `risk.nominalByZone` `risk.dynamic` | 风险暴露口径 | true / true |
| `roads.*` | 封闭/拥堵半径、BPR、绕行系数、`vehicleSpeedCap` | 1000/3000/… |
| `evacuation.*` | `Tmax` `dt` `flexiblePriority` `k3ReservedRatio` `fleet.{ambulance,helicopter,bus,car,subway}`（car=null 自动）`sensitivityAmbulances` | 180/5/true/0.25/15,3,20,null,15 |
| `supply.*` | `trucks` `drones` 速度、载重、航程、`maxIter`、`sensitivityDrones` | 20/10/… |

### 2.2 结果结构（`result`）

```text
version, params, stages[], stageTimes{stage: ms}, elapsedMs, computeMs, log[{t,msg,level}]
scenario   { incident, gas, thresholds, leakRateKgMin, wind{speed,dir,level,name,stability}, dronesGrounded, roadNetwork }
plume      { maxConc, plumeDirDeg, reach{erpg1|2|3:{maxDistM,areaKm2}},
             contours[{threshold, geometry(MultiPolygon), empty}],
             raster{width,height,values[行北→南],max,bounds{west,south,east,north}} }
zones      { mode, buffers, populationMode, populations{erpg3|2|1:{total,children,elderly,working,blocks}},
             circles{r1000,r3000,r5000}, polygons{erpg3|2|1: MultiPolygon}, evacDemand,
             byClassDemand{1,2,3}, shelterInPlace{erpg3|2|1:{1,2,3}}, shelterInPlaceTotal, populationApproximate }
roads      { closedKm, totalKm, ratio, source, approx, closureRadiusM, congestionRadiusM, influenceRadiusM, travelModel }
evacuation { schemes{all|double_amb|no_subway|no_heli|strict: {
               label, evacuated, remaining, total, rate, totalRisk, makespan, k2ZoneRate,
               byClass{1|2|3:{evacuated,total,rate,avgTravelMin}}, byMode{mode:{trips,people}},
               byZone{zone:{evacuated,total,rate}}, objective{obj,z1,z2,z3},
               timeline[{t,remaining,risk}], fleet{mode:{count,trips}},
               schedule[{t,pickup,arrival,k,mode,count,origin,dest,destKind,zone,vehicle,travelMin,
                         legs[{t0,t1,path[[lon,lat]...]}×2]}] }},
             sensitivityAmbulance[{n,rate,k1Rate,evacuated,risk}],
             origins[{id,name,lon,lat,zone,population{1,2,3},sectorPop,rho,rhoLocal,exposureEndMin,distM}],
             destinations{hospitals[],shelters[],subways[]}, modes{...} }
supply     { schemes{truck_only|coordinated|coord_double|drone_only: {
               label, totalTasks, completed, unmet, completionRate, objective, makespan, avgTimeMin, penalty,
               routes{direct,relay,truck,drone}, byCategory{cat:{total,completed,onTime,onTimeRate,avgTimeMin,maxTimeMin,deadlineMin}},
               lifeOnTimeRate, iterations, config,
               schedule[{taskId,cat,qty,demand,demandId,vehicle,vehicleType,supply,relay,route,
                         departure,arrival,deadline,penalty,legs[{type,t0,t1,path}]}] }},
             sensitivityDrones[{n,makespan,avgTime,completed,completionRate,lifeOnTime,penalty,relay}],
             network{supply[],relays[],demand[]}, taskCount, tasksByCategory }
resilience { structural{closureRatio,connectivity,closedKm,totalKm},
             functional{supplyCompletion,supplyMakespan,lifeOnTime,evacRate,evacTotalRisk},
             adaptive{relayTasks,relayIncrement,droneMakespanChange,zoningGain,evacDemandReduction},
             radar[{key,name,value(0~1),note?}] }
```

坐标一律 WGS84 `[lon, lat]`；时间单位 min；人数为整数。

## 3. iframe postMessage 协议

| 方向 | 消息 | 说明 |
|---|---|---|
| 父 → 模块 | `{ type: 'emergency-sim:run', params? }` | 合并参数（浅合并到当前参数）并计算 |
| 父 → 模块 | `{ type: 'emergency-sim:set', siteId?, windPresetId?, view? }` | 切换站点/风况/视图（`overview`/`hazard`/`supply`/`evac`），不计算 |
| 父 → 模块 | `{ type: 'emergency-sim:getResult' }` | 请求最近一次结果摘要 |
| 模块 → 父 | `{ type: 'emergency-sim:ready' }` | 页面加载完成 |
| 模块 → 父 | `{ type: 'emergency-sim:back' }` | 点击模块内“返回首页”（`config.js` 设置 `homeUrl` 时显示） |
| 模块 → 父 | `{ type: 'emergency-sim:result', payload }` | 每次计算完成；`payload = { incident, wind, evacDemand, shelterInPlace, evacuation{scheme:{label,rate,evacuated,totalRisk}}, supply{scheme:{label,completed,total,makespan}}, resilience[{name,value}], elapsedMs }` |

示例见 `examples/iframe-demo.html`、`examples/EmergencySimEntry.vue`。打开时传入事故信息也可用 URL 参数（`lon`、`lat`、`name`、`wind`、`windSpeed`、`windDir`、`stability`、`gas`、`leak`、`view`、`autorun`），见 `docs/部署指南.md` 第 2 节。生产环境建议在两端校验 `event.origin`。

## 4. 数据文件格式

### `facilities.json`
```json
{ "fire_stations": [{ "id", "name", "lon", "lat", "type": "fire_station", "stock": { "life_rescue", "medical", "protection", "basic" } }],
  "warehouses":    [{ "id", "name", "lon", "lat", "type": "warehouse", "assumed": true, "stock": {...} }],
  "shelters":      [{ "id", "name", "lon", "lat", "type": "shelter", "capacity", "relay_candidate"? }],
  "hospitals":     [{ "id", "name", "lon", "lat", "type": "hospital", "beds" }],
  "subway_stations": [{ "id", "name", "lon", "lat", "type": "subway", "capacity", "approx"? }],
  "commute_mode_shares": { "car_ratio", "subway_ratio", "bus_ratio", ... } }
```
数组顺序有意义：与论文一致，按范围筛选后取前 N 个。

### `population.json`
```json
{ "grid": { "lon0", "lat0", "dlon", "dlat", "nx", "ny" },   // lon0/lat0 为西北角；行自北向南
  "cells_rle": [label, run, label, run, ...],               // 行优先游程编码，label 为地块编号，0=无人口
  "blocks": [0, pop1, pop2, ...],                           // 地块人口
  "age_structure": { "children": 0.12, "elderly": 0.15 },  // 全局比例（缺少 block_age 时使用）
  "block_age": { "children": [0, r1, ...], "elderly": [0, r1, ...] },  // 可选：逐地块比例，与 blocks 等长
  "meta": { "approximate": true|false, ... } }
```

### `road_network.json`（可选）
```json
{ "nodes": [lon0, lat0, lon1, lat1, ...], "edges": [u, v, length_m, speed_kmh, ...] }   // 有向边
```

### `yizhuang_boundary.geojson` / `paper_reference.json`
标准 GeoJSON；论文基准结果见文件内 `meta`。
